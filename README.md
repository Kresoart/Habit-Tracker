# Habit Tracker

A simple, single-page habit tracker.

**Live site:** https://kresoart.github.io/Habit-Tracker/

## Features

- Habits for every day, chosen weekdays, or a number of times a week
- Habits to quit, counted in clean days, with a one-tap "I slipped"
- Priorities and "anytime" habits
- Skip a day or pause a habit without breaking your streak
- Notes on the days you slip, and a "why" for each habit
- Week strip, month calendar and a weekly review

## Data

Everything is stored in your browser (localStorage) on the device you use. Clearing site data removes it.

## Files

- `index.html` — the whole app: markup, styles and script in one file.
